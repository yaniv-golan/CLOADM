Questions people ask

What is CLOADM?

An emulator of the Dragon, the Tandy Color Computer and the MC-10 that runs in a web page. I named it after the BASIC command that loads machine code from tape. There is nothing to install and no account. It boots straight into a welcome menu, and you can drop tapes, disks, cartridges and programs on the screen. It is pre-release, so expect rough edges.

Which machines does it run?

The Dragon 32, 64, 200, 200-E, 64 Plus, Professional (Alpha) and the Tano Dragon 64; the Tandy Color Computer 1, 2, 2B and 3; the MC-10 and Matra Alice; and the clones Prológica CP 400, Dynacom MX-1600, LZ Color64 and Codimex CD-6809. Help's list of the machines says which ROMs each one takes.

Why are there no ROMs?

The BASIC and DOS ROMs belong to Microsoft, Tandy, Dragon Data and others, and I have no right to hand them out. So CLOADM never ships them, downloads them or fetches them for you. Without them, firmware I wrote still runs: the welcome menu, LIZA, a colour and sound demo, the Claude chat, and the games 2048 and Minesweeper (with 32K or more). So do machine-code programs that don't call BASIC.

How do I add my ROMs?

Drop the files on the screen: single files, a folder or a ZIP, with any names. CLOADM recognises each ROM by its CRC32 and puts it in every machine it fits. Add ROMs in the header shows what each machine needs and what each file turned out to be. I can't tell you where to download them; the ROMs page says what I can. If you own the machine, dumping your own is the cleanest route.

Is it legal? Where does the firmware come from?

Emulating hardware is legal; copying someone else's ROM is not, which is why I don't. What runs when you add no ROMs is firmware I wrote for this project: a small boot program, the welcome menu, LIZA and the games, all with their source in the repository under the MIT License. None of it is copied from a ROM.

How accurate is it?

I check it against MAME 0.264, the reference emulator. The same test firmware runs in both, and every instruction must match in every register and cycle count. Display modes are compared pixel for pixel. That holds where MAME has the hardware; the exceptions, such as part of the CoCo 3's video, are in the verification notes. Where I differ from MAME on purpose, I need a source: the known differences.

What about privacy?

Your ROMs, programs, disks and settings stay in your browser: there is no account, and I run no server that sees them. A share link holds the machine and the moment, never your ROMs. Once you ask Claude something, it can read the screen and any memory (ROM areas included) without asking, and it also gets the machine's facts and the chat so far; these go to Anthropic with your key. Only changes to the machine ask you first.

What is in a share link?

The machine, its settings and a snapshot of the moment. The snapshot sits after the # in the link, a part browsers never send to a server, so I never see it. It holds no byte of your ROMs: it names them by CRC, and CLOADM refuses to make the link if any ROM code is left in it. Whoever opens it needs their own copies of the same ROMs.

Do I have to use Claude?

No. Nothing goes to Anthropic until you ask it something. To hide it completely, set Settings → Machine → Claude features to Off: no button or link can start a chat then. If you do use it, your Anthropic key is kept in your browser and sent only to Anthropic. I never put it in the emulated machine, snapshots, share links or exported settings.

Is this a business?

CLOADM is free: the emulator, the games, WYRMFIRE and sharing, with no account. The optional Claude chat costs tokens: use your own Anthropic key, or use CLOADM inside Claude with your Claude account. I keep nothing.

Does it work offline? Can I install it?

Yes. After one visit it works with no connection, your ROMs and library included, since they live in your browser. Install CLOADM… in the app bar, beside Help (behind Menu on a phone), makes it an app with its own window. On phones and tablets an on-screen keyboard and a touch joystick appear.

Was AI used?

Yes. CLOADM was built with Claude. I don't take its word for correctness: every chip is checked independently against MAME, instruction by instruction and every pixel, using the project's own firmware, so a mistake shows up as a difference whoever made it. How it is verified.

Is it Doom?

No. WYRMFIRE is a new engine that reads Doom-format levels; it ships with a Freedoom level.

Something broke. How do I tell you?

In the emulator, Copy bug report (in the command box, Ctrl K) shows you the report before it copies anything: the version, the machine, the browser and the file you loaded last. It never holds your ROMs or your key. Nothing is sent: paste it into a new issue on GitHub.
