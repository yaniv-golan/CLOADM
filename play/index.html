The emulator needs to be opened through a web server

Browsers don't run this page's scripts when it is opened straight from a file.

From the folder that holds CLOADM (with index.html and play/), run one of these, then open http://localhost:8000/play/:

python3 -m http.server 8000
npx serve -l 8000 .
