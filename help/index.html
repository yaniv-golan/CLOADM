Commands and shortcuts

Press Ctrl K (⌘ K on a Mac) anywhere, or choose Commands… in the app bar's links (behind Menu on a phone), to open the command box. With nothing typed it lists every command; type to filter them, or type a question for Claude. Commands run in the page and are never sent to Claude.

Shortcuts

  • Ctrl K (⌘ K on a Mac): the command box
  • Ctrl B: switches between the Claude chat and your BASIC session
  • Esc = BREAK · Home = CLEAR · Backspace = ← (on a Mac without Home: Fn+← or Fn+Delete, as under Keys)
  • Esc in the full-screen chat: while a reply streams it stops the reply; with a line typed it drops the line; on an empty, idle prompt it leaves the chat
  • Esc while Claude is paused: stops Claude

Claude: getting an API key

Where? Get a key at console.anthropic.com, under API keys, and paste it into the key field beside the chat.
What does it cost? Use is billed to your Anthropic account: see pricing.
No key? Use CLOADM inside Claude instead: see Use with Claude.

What Claude can do

Reads (always): the machine's model and settings, the screen's text (not graphics), memory, and disassembly.
Acts (only with your permission): types, presses BREAK, POKEs memory, loads BASIC programs, assembles and loads machine code, and runs programs. A restore point is made first.
What Claude reads goes to Anthropic with your key. That includes the machine's memory, so any ROM areas it reads are sent too. CLOADM itself never uploads your ROMs.

ROMs

Do I need them? Only for BASIC and programs that use it. The Welcome menu, LIZA and the colour demo run without.
Where do I get them? Dump them from your own machine, or see where to get ROMs. They're copyrighted by Microsoft, Tandy, Dragon Data and others; check your rights. CLOADM never downloads them.
Which file goes where? It doesn't matter. Drop them all; CLOADM recognises each by its contents.
Can I share a snapshot that uses my ROMs? Yes. A share link never holds a ROM or a cartridge: it names the ones the snapshot used, and the person opening it needs their own copies of the same versions. Without them, CLOADM says which ROMs to add and opens the snapshot once they're in.
Do my ROMs ever leave my browser? CLOADM never uploads them and never puts them in share links or exported settings. If you use Claude, what it reads from the machine's memory (ROM areas included) is sent to Anthropic as part of your conversation.

Install CLOADM as an app on this device

Why? Installed, CLOADM opens in its own window, away from the browser's tabs and address bar, and works offline. The files it keeps (ROMs, tapes, disks, programs) are the same ones either way.
Chrome or Edge on a computer. Click the install icon in the address bar (a screen with an arrow, or a ⊕), or open the browser menu ⋮ and choose Install CLOADM… (in Edge: Apps → Install this site as an app). In CLOADM it is at the foot of the machine menu (the machine-name button, top left).
Chrome on Android. Open the menu ⋮ and choose Install app, or on older versions Add to Home screen.
Safari on a Mac. In Safari: File → Add to Dock.
Samsung Internet. Tap ☰ and choose Add page to → Home screen.
Firefox on Android. Open the menu ⋮ and choose Install (older versions: Add to Home screen).
iOS Safari. Tap Share (the square with an arrow), scroll down and choose Add to Home Screen, then Add.
Chrome or Edge on iOS 16.4 and later. The same steps: Share, then Add to Home Screen.
With Claude? Using CLOADM with Claude is separate: see Use with Claude.

Quick fixes

Black screen, no OK. A required ROM is missing or not recognised. A box on the screen says which; Add ROMs shows them.
No sound. Click the screen or press a key once; browsers keep sound off until you do.
Tape won't load. Check it's for this machine, and undo any speed POKE first: POKE 65494,0 undoes POKE 65495,0, and POKE 65496,0 undoes POKE 65497,0.
Disk shows nothing. DIR and the other disk commands need the machine's disk ROM: the DragonDOS or Delta cartridge on a Dragon, Disk BASIC on a CoCo. Without it a disk still goes in, for programs that read it directly, and the drives under the screen say so. Check the disk is for this machine too: DragonDOS disks are for a Dragon, RS-DOS disks for a CoCo, and CLOADM says which a disk is.
Wrong symbols. Keys type what they say, so shifted symbols follow your keyboard, not the original layout.
ROMs gone in a new browser. Use Save ROM pack in the old one and drop the file on CLOADM in the new one.
