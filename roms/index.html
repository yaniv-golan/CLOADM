Where to get ROMs

The Welcome menu, LIZA and the demos run without them. For BASIC, CLOADM needs the contents of the machine's ROM chips. You add them once, and they stay in this browser.

Get the files

The community-run Color Computer Archive keeps the ROM sets XRoar uses: colorcomputerarchive.com/repo/ROMs/XRoar.

The file names each machine expects are in the table below.

It isn't part of this project and CLOADM never connects to it. Whether you may download from it depends on where you live and on the rights holders' terms.

Dump your own

If the machine is still in the attic, its ROMs are the cleanest source: read the chips with an EPROM reader, or run a program on the machine that sends the ROM out through the cassette or serial port.

They're copyrighted

ROMs are copyrighted by Microsoft, Tandy, Dragon Data and others. CLOADM doesn't include them and never downloads them. Check your rights first.

Add them to CLOADM

  1. 1
    Any names, any order. File names don't matter: CLOADM recognises ROMs by their contents.
  2. 2
    Keep them here. ROMs stay in this browser. CLOADM never uploads them and never puts them in share links or exported settings. If you use Claude, what it reads from the machine's memory (ROM areas included) is sent to Kapai (or to Anthropic, with your own key) as part of your conversation.
  3. 3
    Drop the lot on the emulator. Files, a folder or a ZIP. One drop sets up every machine they fit; Save ROM pack… takes them to another browser.
